# Medium: handover

The reader is the next conversation's Claude (`audience-claude`) — you, minus everything this context holds. The practice and its pairing with the testament are the `handover` skill; this file is the medium's format.

**Three parts, short:**

- **Where things stand** — the state of the work, in a few lines.
- **What is in flight** — the next thread, in order; what is waiting on whom.
- **What to search the memory store for** — the searches, by name, that surface the memories this thread needs. This is the heart: the durable knowledge lives in the store; the handover carries the keys.

**One-shot and perishable.** It serves once, at the next conversation's start, then dies. Durable understanding put only here dies with it — that belongs in the store. If a line does not help the reader resume, cut it.
