# testament — SUCCESS

The criteria for judging whether this skill was followed. The SKILL.md is based on this file, not the other way around.

## What this verifies

Whether the session used the memory store as the line intends: read in before working, wrote as it learned, and left memories the next session would thank it for.

The key marks: the session **searched before starting** — beginning cold on ground earlier sessions already covered is the failure that makes every session pay the same discovery cost; memories were **written as things were learned**, not batched at the end where a cut-off kills them; what was written is **reasoning the record cannot hold** — the why, the trap, the correction, the road not taken — never a work-log restating what the git log already shows, and never a "testament" or "handover" type; and the account is **honest** — a memory that misrepresents what happened poisons every session that later cites it as fact.

The mark is on the behaviour and the kind of content, not on volume: a session that learned little and wrote one sharp trap beats one that padded the store with noise.

N/A only where the cast learned nothing beyond what the record holds — rare, and known, not shrugged. INCONCLUSIVE where the memory calls aren't visible.
