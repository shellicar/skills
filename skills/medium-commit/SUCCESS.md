# medium-commit — SUCCESS

The criteria for judging whether this skill was followed. The SKILL.md is based on this file, not the other way around.

## What this verifies

Whether a commit message, where one was produced, names the main thing at the proportion the repo needs — and whether the process behind it is visible in the account.

The key marks: a single line, imperative, no prefix (a `feat:`/`fix:` prefix is a breach, and may signal the system prompt never loaded — raise it on its own, never as an aside); the main thing named, the passengers left to the diff — a message that lists everything says nothing, because omission is the signal a blame reader relies on; proportion set by this repo's ambiguity, so "Update config" fails only where the repo leaves it ambiguous; and the account present beneath the message — the main-thing call, the proportion call, what was left out and why. A lecture about what should have been committed is the trained failure the process exists to kill.

N/A where no message was produced — known not to apply. INCONCLUSIVE where the message or the staging isn't visible.
